# TailorLearn

面向个性化学习分析的材料结构化工具。当前实现包括 AI 厂商配置、材料与数据、
课本/课程标准导入、本地 OCR、章节切分、AI 结构化、批量审核、六类学情数据
管理，以及按主题范围梳理学习内容与要求的成果包。

## 启动

```bash
uv sync
uv run streamlit run src/tailorlearn/app.py
```

也可以运行：

```bash
uv run tailorlearn
```

AI 参数页支持保存多套 OpenAI-compatible Chat Completions 配置。API Key 只写入
本机 `.local/ai_profiles.json`，不读取环境变量，也不写入 `db/`。

## 学习内容梳理（任务 1）

侧边栏“学习内容梳理”页面按学情数据集中的主题范围整理成果，包含：

- 学习内容与要求清单：学习内容、要点、对应指标、课标要求原文与层级；
- 必要联系：先备、应用、并列、对比，逐条写明依据；
- 材料出处：课标与教材的文件、章节、页码、原文引文及逐字核对结果；
- 范围边界：已纳入主题、课标页码、教材章节，以及未纳入的章节说明；
- 成果包：`outline.json`、`items.jsonl/csv`、`relations.jsonl/csv`、
  `references.json/csv`、`scope.json`、`field_definitions.csv` 和 `README.md`。

规则梳理不需要 API：按课标条目顺序、教材章节顺序和术语重合自动对应，并回查
每条引文所在页面。配置 AI 厂商后可使用“AI 梳理”，AI 起草的条目一律进入
待复核状态，仍会逐条回查课标页和教材页。

也可以离线生成：

```bash
uv run tailorlearn outline --dataset-id <dataset_id> --themes T01 T02 T03
```

默认使用全部主题和全部教材切片；`--ai` 使用当前厂商配置。成果目录为
`db/outlines/<run_id>/`。

## 材料与数据

侧边栏“材料与数据”统一管理课本、课程标准和六类学情数据。顶部水平导航可切换：

- 课本
- 课程标准
- 学生
- 课程要求
- 题目与材料
- 测验节点
- 作答记录
- 字段说明

课本和课程标准提供“浏览 / AI结构化和管理 / 导入和导出”栏目；
六类学情数据提供“浏览 / 编辑 / 导入和导出”栏目，作答记录额外提供“异常检测”。

六类学情数据的“浏览”栏目只读，仅查看已有数据集和记录；“编辑”栏目用于修改已有记录；
“导入和导出”栏目直接显示“新建学情数据集”表单，不再列出已有数据集卡片；已有数据集
先在浏览或编辑栏目中打开，再切到导入和导出栏目导入 CSV。课本和课程标准的“导入和导出”
仍只负责材料 PDF 的导入与导出。

AI 结构化和管理页支持查看结构化状态比例、内联编辑单元、选择单元批量确认、
软删除和回收站恢复。“重新识别”会重跑 PDF 文字/OCR 与章节切分；
结构化则继续使用现有 AI 分章节识别流程。导入和导出页统一提供数据导入与下载入口。

六类学情数据支持按数据集分别导入、导出和维护以下 CSV：

- 课程要求
- 题目与材料
- 模拟学生
- 测验节点
- 作答记录
- 字段说明

文件名和列顺序不参与类型判断。导入前会按字段名自动匹配，必要时可人工映射并
保存别名。页面在写入前展示新增、更新、未变化、人工修改冲突和质量问题预览；
同一类型重复导入时按业务主键合并，不会静默覆盖人工修改。

作答记录保留全部修订版本，可切换“仅最新修订”；删除默认是软删除并可恢复。
“数据质量”页签会检查必填字段、关联引用、评分范围和评分状态一致性。详细存储
约定见 [db/README.md](db/README.md)。

## 离线导入

```bash
uv run tailorlearn import-pdf \
  --name "七年级数学课本切片" \
  --material-type textbook \
  --subject 数学 \
  /path/to/textbook-slice.pdf
```

成功后可在界面中审核，或使用当前厂商配置执行：

```bash
uv run tailorlearn structure --document-id <document_id>
```

`uv run tailorlearn list` 可查看材料与文档 ID。
