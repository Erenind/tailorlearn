# 早间 AI 学生诊断与教师复核更新日志

**日期：** 2026-11-09 上午  
**分支：** `codex/learning-analytics`  
**核心提交：** `03f88a9 feat: add reviewable ai student diagnosis`

## 本轮目标

在既有学生学情图表和确定性统计的基础上，增加 AI 学生诊断草稿能力。AI 不计算分数、不判定掌握状态，只解释已核验的学生证据，并交由教师复核。

## 新增功能

### 1. 学生分析中的 AI 诊断页签

- 在“学生分析”中新增“AI 诊断与教师复核”页签。
- 支持为当前学生、当前测验节点生成一份诊断草稿。
- 支持按“数据集＋班级＋具体节点”为整个班级批量生成草稿。
- 未配置 API 时，仍可查看已有草稿，并显示安全的配置提示。

### 2. 脱敏学生证据包

AI 只接收：

- 学生编号、测验节点；
- 主题和指标的已观察得分率、有效记录数量、待评分数量、未作答数量、证据状态；
- 作答记录编号、题目编号、得分、满分与指标编号；
- 当前节点内可用、且学生尚未作答的候选材料编号。

AI 不接收姓名、原始作答文本、整库数据、其他学生无关信息、API Key。

### 3. 结构化 AI 草稿与越界校验

AI 草稿采用 JSON，包含：

- 谨慎摘要；
- 已观察到的表现及其作答记录/指标依据；
- 信息缺口；
- 仅引用已有候选材料的补充观察建议；
- 教师下一步行动。

保存前会校验：

- 主题、记录编号、指标编号必须在证据包内；
- 推荐材料必须是当前节点已有且该学生未作答的候选材料；
- 信息不足时不得使用“未掌握”“掌握不足”“能力下降”等结论；
- JSON 解析或结构校验失败时不保存草稿。

### 4. 持久化任务与教师审核

- 班级批量任务逐名保存排队、处理中、成功、失败和重试状态。
- 页面刷新或服务重启后，未完成任务可继续处理。
- 教师可修改摘要、填写备注，并采纳或拒绝草稿。
- 保留原始 AI 响应、证据包、厂商/模型元数据和教师修订记录；不保存密钥。
- 学情数据发生更新时，待审核或已采纳的旧草稿自动标记为“需更新”。

## 数据边界

- 仅统计未删除的最新修订、已评分、分值有效且关联完整的作答。
- 待评分、未作答、异常数据和关联缺失不等同于未掌握。
- 学生主题/指标少于 3 条有效记录时，证据有限或信息不足；AI 只能提出补充观察。
- 趋势仍要求前驱和后继节点都有充分证据；AI 不能越过该规则自行判断能力变化。

## 验证结果

- 当时全量自动化测试：`44 passed`。
- 单元测试覆盖证据包脱敏、班级批量任务、单学生任务、教师采纳/修订、数据更新失效、失败重试、任务进度和 AI JSON 解析。
- 手动核验“模拟2”数据下，学生页面可显示 AI 页签；无 API 配置时不会发起请求，并给出配置提示。
