# 下一阶段开发方向选择

> 用途：在开始下一轮功能开发前，由团队选择一个主线方案及可选增强项。本文不代表已批准实施的范围。

## 0. 当前基础与共同约束

当前系统已经具备：

- 基于最新、有效、已评分作答的学生/班级统计、图表、证据链、补充观察和快照比较；
- 学生级 AI 诊断草稿、持久化批量任务、失败重试、教师采纳/拒绝与数据更新后的失效标记；
- OpenAI-compatible 厂商配置、连接测试、JSON 校验与本地密钥保存。

下列任何方案都必须遵守：

1. 待评分、未作答、异常或关联缺失的数据不等同于“未掌握”。
2. 只有达到证据充分阈值的统计才可形成正向或需关注的观察；证据不足只显示“待补充观察”。
3. AI 不计算分数、不判定掌握状态；它只解释确定性服务提供的证据包并输出待审核草稿。
4. AI 的每项观察必须能回链到已有主题、指标、作答记录或候选材料；推荐只允许使用现有且未作答的材料。
5. 所有 AI 输出保留模型、提示词/结构版本、证据包、原始响应、教师复核结果和失效状态。

## 1. 主线方案（请选择 1 项）

### A. 班级教学建议闭环（推荐）

**目标：** 补齐“班级分析—教学建议—教师审核—后续观察”的赛题闭环。

**实现范围：**

- 从班级主题统计中只选取证据充分的共性表现，以及明确的数据缺口；
- 构建脱敏班级证据包，包含班级、节点、主题、指标、有效记录数量、得分率、证据状态和可用材料；
- AI 起草教学目标、分层活动、补充观察、课后检查与教师行动建议；
- 新增“教学建议”页面，支持当前班级/节点生成、查看证据、编辑、采纳、拒绝和失效提示；
- 将教师采纳的建议与后续分析快照关联，显示数据是否发生变化，但不宣称因果关系。

**验收：** 每条建议都有证据来源；证据不足主题只出现补充观察；教师可审核；数据更新后旧建议需更新。

**风险：** 需要设计班级证据的最小聚合粒度与教师审核交互。

### B. 教师工作台与干预记录

**目标：** 先提升教师日常使用效率，暂不扩展 AI 的班级生成能力。

**实现范围：**

- 建立统一待办：待评分、证据不足、待审核 AI 草稿、数据更新后失效的诊断、重点观察学生；
- 支持从待办直接跳转学生分析、班级分析或 AI 草稿；
- 教师记录干预日期、对象范围、采用材料、行动说明和备注；
- 关联前后分析快照，展示有效记录数、得分率、证据状态的变化。

**验收：** 教师能在一个入口完成筛选、处理、记录与回看；所有“效果”均以观察到的数据变化表述。

**风险：** 竞赛中的 AI 创新展示较弱，但能为后续 AI 教学建议提供高质量人工闭环数据。

### C. AI 可靠性评测与真实 API 联调

**目标：** 在扩展功能前先验证模型真实可用性、成本与输出合规性。

**实现范围：**

- 建立脱敏的固定评测样例：证据充分、证据不足、待评分、异常数据、推荐材料为空等场景；
- 记录模型、耗时、请求大小、解析/校验结果、失败原因、教师采纳率；
- 对学生诊断执行真实 API 冒烟测试、限流/超时/失败重试验证；
- 建立“禁止结论”与“引用越界”自动验收集，防止 AI 把信息不足写成未掌握。

**验收：** 每次 API 联调可复现质量报告；违规输出被拒绝入库；失败任务可恢复且不重复丢失。

**风险：** 对现场演示的可见功能增量较少，需要有效 API 配置和预算。

### D. 竞赛成果包与演示流程

**目标：** 优先将已有能力组织为清晰、可信、可复现的竞赛展示。

**实现范围：**

- 预置一个学生个案、一个班级对比个案、一个“信息不足—补充观察”反例；
- 导出图表、统计、证据链、AI 草稿及教师复核记录；
- 制作演示导航：数据导入 → 数据质量 → 图表分析 → AI 草稿 → 教师审核 → 快照比较；
- 生成答辩用的规则说明与典型案例说明。

**验收：** 离线演示可完整走通；每个结论都有页面可回查；成果包不含 API Key 与本地数据库二进制文件。

**风险：** 不能代替后续功能开发，适合比赛时间紧或已进入答辩准备阶段。

## 2. 可选增强项（可多选）

### E1. 班级分层教学

- 仅按“证据充分且表现较高”“证据充分需关注”“待补充观察”分组；
- 为每组列出不同教学活动和已有材料；
- 不建立“未掌握学生”标签。

**适配：** A。

### E2. 多策略建议对比

- 为同一班级证据包生成“理论先行”“实践先行”“间隔复习”多种策略草稿；
- 展示相同证据下的不同教学路径，由教师选用并编辑；
- 不允许策略假设学生不存在的数据特征。

**适配：** A、C。

### E3. 测验蓝图与覆盖缺口

- 建立主题—指标—节点—题目的覆盖矩阵；
- 识别证据不足是由题目缺失、待评分还是学生未作答导致；
- 指导下一次测验补充何种观察，而非给学生贴标签。

**适配：** A、B、D。

### E4. AI 建议质量看板

- 展示草稿数量、校验拒绝率、失败率、教师采纳/修改/拒绝比例；
- 按模型和提示词版本比较；
- 支持定位错误类型，但不暴露学生敏感内容。

**适配：** C，也可作为 A 的质量保障。

### E5. 典型案例一键导出

- 导出单个学生或班级的证据、图表数据、建议草稿和审核状态；
- 形成可提交的 JSON/CSV/Markdown 成果包；
- 默认脱敏，排除 API Key、原始答题文本和 SQLite 文件。

**适配：** D，也可和任意主线组合。

## 3. 推荐组合

### 组合 P1：赛题闭环版（推荐）

选择：**A + E1 + E3 + E5**。

形成“班级证据 → 分层教学/补充观察 → 教师审核 → 导出案例”的完整闭环，功能与赛题目标最直接对应。

### 组合 P2：稳健上线版

选择：**C + B + E4**。

先验证真实模型的合规与稳定性，再用工作台让教师处理既有诊断和记录干预；适合 API、预算或评审标准尚不明确时。

### 组合 P3：答辩冲刺版

选择：**D + E5 + E3**。

优先完成可复现演示、典型案例与数据边界说明；适合功能已经足够、比赛临近时。

### 组合 P4：AI 展示版

选择：**A + E2 + E4 + E5**。

突出“同一证据、多种可审核教学策略”和 AI 质量控制；适合希望强化 AI 创新表达时。

## 4. 请选择

请按下列格式回复：

```text
主线：A / B / C / D
增强项：E1, E2, E3, E4, E5（可不选或多选）
组合：P1 / P2 / P3 / P4（如直接选组合，可省略前两项）
优先级：先做什么，后做什么（可选）
```

例如：`组合：P1；优先级：先做班级证据与审核，再做分层教学和导出。`
