# 学情分析与可视化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` or `superpowers:executing-plans` task-by-task.

**Goal:** 提供以证据充分度为基础的学生与班级分析页面，并形成“补充观察—前后变化—可核对证据”的闭环。

**Architecture:** 由独立分析服务从现有学情数据表读取最新有效作答，生成主题、指标、趋势、班级比较及证据包。Streamlit 页面仅渲染服务结果；分析快照保留聚合结果，支持之后导入数据后的差异比较。

**Tech Stack:** Python 3.12、SQLite、Streamlit、Plotly、pytest。

## 全局约束

- 缺少、待评分或无效记录不得解释为未掌握。
- 所有图表默认仅使用未删除的最新修订、已评分且分值有效的记录。
- 数据不足时显示证据状态和补充观察建议，而不是填充为零或作负面标记。
- 结果必须可回溯到记录、题目、指标及已有课程材料。

## 任务

1. 增加 Plotly 与平台兼容的基线测试，修复 Windows 下 POSIX 权限位断言造成的既有失败。
2. 用测试先行实现分析数据模型、有效记录筛选、主题/指标/趋势/班级聚合和证据充分度。
3. 实现补充观察建议、分析快照和快照差异比较；快照保存筛选范围、统计结果和变更日志截点。
4. 增加学生分析页面：筛选、证据摘要、雷达图、指标条形图、趋势图、证据明细和补充观察。
5. 增加班级分析页面：主题分组柱状图、分布图、充分度热力图和共性问题。
6. 增加 JSON/CSV 导出与典型案例核对数据；运行单元、页面和全量回归测试。

## 核验重点

- 作答修订、待评分、异常分值和引用缺失的筛选正确。
- 学生主题节点至少 3 条、班级至少 5 名学生与 10 条记录才给出充分结论。
- 缺失前驱/后继节点或 T03 前驱记录不足时不生成趋势结论。
- 补充建议仅引用现有且与证据缺口相符的材料。
- 快照差异列出受影响的学生、班级、主题、指标和新增记录依据。
