# P1 班级教学建议闭环更新日志

**日期：** 2026-11-09  
**分支：** `codex/learning-analytics`  
**状态：** 已实现，等待团队验收

## 本轮目标

完成“班级证据 → 分层教学建议 → 教师审核 → 脱敏案例导出”的教师端闭环，对应赛题的班级学情分析、教学建议与结果可核对要求。

## 新增功能

### 1. 教学建议页面

- 侧边栏新增“教学建议”入口。
- 教师可选择学情数据集、班级和测验节点。
- 页面展示班级主题统计、测验蓝图、分层观察、AI 草稿、教师审核和案例导出。
- 未配置 API 时，页面仍可查看确定性证据和历史草稿，并明确提示配置方式。

### 2. 班级证据包与分层

- 仅使用未删除、最新修订、已评分、分值有效、关联完整的作答。
- 班级主题至少覆盖 5 名学生和 10 条有效记录，才标记为“证据充分”。
- 学生主题至少有 3 条有效记录，才进入表现分层。
- 分层结果包括：
  - `observed_higher`：充分证据下，已观察得分率不低于班级同主题；
  - `needs_attention`：充分证据下，比班级同主题低至少 20 个百分点；
  - `observed_other`：充分证据下，接近班级同主题；
  - `needs_observation`：学生或班级证据不足，待补充观察。

### 3. 测验蓝图与材料边界

- 展示主题—指标—可用题目—有效记录—待评分—未作答的覆盖情况。
- 明确区分 `observed`、`pending_review`、`unanswered_only`、`no_available_material` 与 `needs_observation`。
- 候选材料只从当前节点已有的题目或学习卡中选择。
- 每条材料建议附带适用学生编号，已完成该题目的学生不会被推荐该材料。

### 4. AI 草稿与教师审核

- AI 只接收脱敏班级证据包，不接收姓名、原始作答文本、整库数据或密钥。
- AI 只能引用证据包中已有的主题、指标、分层学生和候选材料。
- 越界引用、推荐已作答材料、空摘要，或出现“未掌握”“掌握不足”“能力下降”等表述的草稿会被拒绝保存。
- 草稿状态支持待审核、采纳、拒绝和数据更新后失效。
- 教师可编辑摘要、记录审核备注，再采纳或拒绝建议；原始草稿和教师修订同时保留。

### 5. 典型案例导出

- 可导出脱敏 JSON、Markdown，以及班级主题统计、测验蓝图、教学分层三份 CSV。
- 导出不包含 API Key、SQLite 文件、原始作答文本或 AI 原始响应。

## 数据原则

本轮继续遵守“数据不足不判定未掌握”：

- 待评分、未作答、异常分值、引用缺失和证据不足均不等同于未掌握。
- 证据不足时仅提示补充观察，不给出负面能力结论。
- AI 仅解释确定性统计结果，不参与算分或掌握判定。
- 数据发生变化后，已采纳或待审核的建议会自动标记为需更新，避免旧结论被误用。

## 验收建议

1. 打开“教学建议”，选择有数据的班级和节点，检查主题统计、蓝图与分层。
2. 确认待评分、未作答和证据不足内容没有被写成“未掌握”。
3. 在配置 API 后生成一份草稿，检查引用的主题、指标、学生和材料均来自页面证据。
4. 编辑并采纳草稿；再更新一条学情记录，确认旧建议显示为“需更新”。
5. 下载 JSON、Markdown、CSV，确认内容可核对且不含敏感数据。
